# 小程序嵌入 H5 具体怎么做

一句话：东鹏小程序里放一个全屏的 `<web-view>`，里面打开我们的 HTTPS 页面。用户看到的是我们的 Vue3 H5，壳是他们的小程序。

```
用户点活动
    → 东鹏小程序打开 web-view 页
    → 小程序 wx.login，把 ticket 拼进我们的网址
    → <web-view src="https://活动域名/qa?ticket=xxx">
    → 我们 H5 用 ticket 换用户，再问答、抽奖
```

---

## 1. 小程序侧（东鹏改，通常就一个页面）

`pages/webview/index.wxml`（这一页只能放 web-view，会铺满全屏）：

```xml
<web-view src="{{url}}" bindmessage="onMessage"></web-view>
```

`pages/webview/index.js` 示意：

```js
Page({
  data: { url: '' },
  onLoad() {
    wx.login({
      success: (res) => {
        // code 发给东鹏服务端，换 ticket（不要把 openid 明文塞 URL）
        wx.request({
          url: 'https://东鹏接口/换ticket',
          data: { code: res.code },
          success: (r) => {
            this.setData({
              url: 'https://我们的域名/qa?ticket=' + r.data.ticket
            })
          }
        })
      }
    })
  },
  onShareAppMessage() {
    // 分享卡片必须写在小程序这一页，H5 里调不了微信分享
    return {
      title: '东鹏问答抽奖',
      path: '/pages/webview/index',
      imageUrl: 'https://...'
    }
  },
  onMessage(e) {
    // H5 postMessage 过来的数据（分享、返回、关闭时才会带到小程序）
  }
})
```

活动入口（banner、按钮）跳转：

```js
wx.navigateTo({ url: '/pages/webview/index' })
```

分享回来也必须进这一页，不能直接打开一个普通 HTTPS 链接当小程序。

---

## 2. 后台要配的（不做这一步，web-view 是白屏）

在[微信公众平台](https://mp.weixin.qq.com) → 小程序 → 开发管理 → 开发设置：

1. **业务域名**：加上我们 H5 的域名（必须 HTTPS、已备案）
2. 把下载的 **校验文件** 放到 `https://域名/xxxxx.txt`（站点根目录，不能跳转）
3. 若小程序要下载海报图保存相册：再配 **downloadFile 合法域名**

个人主体小程序不能用 web-view。东鹏企业主体才可以。

---

## 3. 我们 H5 侧（Vue3 照常做）

就是普通 Vue 路由页面，例如 `/qa`。在小程序里打开时，多做三件事：

**进页换用户**

```
打开 https://域名/qa?ticket=xxx
  → 前端把 ticket 交给我们 ThinkPHP
  → 我们服务端调东鹏「ticket 换用户」
  → 发我们自己的 token，再开始问答
```

**判断自己在小程序里**（需引入微信 JSSDK）：

```js
wx.miniProgram.getEnv((res) => {
  if (res.miniprogram) {
    // 在小程序 web-view 里
  }
})
```

**需要小程序帮忙时**（返回、分享文案等）：

```js
wx.miniProgram.postMessage({
  data: { type: 'share', title: '我刚答完题' }
})
wx.miniProgram.navigateBack()
```

H5 **不能**在 web-view 里自己做：`wx.login`、拿手机号、保存到系统相册、直接调起分享卡片。这些都要小程序页面配合。

---

## 4. 和这次玩法怎么接

```
进小程序活动入口
  → 小程序授权（wx.login + ticket）
  → web-view 打开我们 H5
  → 我们换用户（没身份不让玩）
  → 问答
  → 问答结束 → 抽奖（服务端校验已完答）
```

责任划分：

| 谁 | 做什么 |
|----|--------|
| 东鹏小程序 | web-view 页、业务域名、login 换 ticket、分享、保存相册（若需要） |
| 我们 | Vue 问答/抽奖页、ThinkPHP、用 ticket 换用户后走自己的逻辑 |
| 东鹏服务端 | code 换 openid、签发 ticket、提供「ticket 换用户」接口 |

---

## 5. 常见坑

- 域名没配业务域名，或校验文件不是根路径：web-view 空白
- 不是 HTTPS：打不开
- 把 openid 写在 URL 上：能伪造，抽奖会被刷
- 以为 H5 里能弹微信授权页：小程序 web-view 里经常失败，必须小程序先 login
- `postMessage` 不是即时的，用户返回/分享/关掉 web-view 时小程序才收到；要立刻保存图片，应 `navigateTo` 到小程序原生页去保存
