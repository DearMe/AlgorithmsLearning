# 已定玩法（按附件一）

活动：学产品知识拿金奖好礼。

1. 进入页面 → 微信授权弹窗。成功进首页，失败回上一页。
2. 授权后用微信身份查是否已参与：已参与 → 结果页；未参与 → 答题页。
3. 从题库随机抽 5 题，每题选择题，不能跳过、不能回上一题。答对提示正确并进入下一题；答错展示正确答案并进入下一题。
4. 5 题结束：答对 ≥ 3 进入抽奖；答对 < 3 回活动首页。每人答题次数有限（次数 X，待甲方定）。
5. 抽奖：点「开始抽奖」播动画，按服务端结果展示中奖/未中奖。
6. 实物奖：展示奖品图，「立即领取」填姓名、电话、收货地址。
7. 可跳转会员中心 / 公众号。
8. 服务端记录：参与、答题对错、抽奖结果。

技术口径不变：小程序 web-view 打开 H5；小程序登录换用户后走我们系统。服务器、环境、登录/发券接口由东鹏提供（范围边界 1.4）。
