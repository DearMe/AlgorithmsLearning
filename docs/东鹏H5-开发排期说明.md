# 开发排期怎么回（内部）

对方问的是预期完成时间。按附件一功能和范围边界 1.4 回，用「前置条件 + 工作日」，不要甩一个没有前提的日期。

## 三项分别是什么

| 对方问的 | 你交什么 | 建议工期 | 起算条件 |
|----------|----------|----------|----------|
| 原型图 | 可点击流程稿，假数据，不还原视觉 | 2 个工作日 | 附件一已确认即可开工 |
| 开发完成 | H5 + ThinkPHP + 抽奖后台，接我们自己的接口 | 8 个工作日 | 全部视觉到齐，题库/次数X/奖品概率已确认 |
| 联调 | 接东鹏登录、部署到他们环境、小程序 web-view 打通 | 3 个工作日 | 换用户接口+文档+测试号+服务器权限+业务域名都到 |

8 个工作日能压住，是因为已有 ThinkPHP + Vue3 微信 H5 项目可复用。若视觉改版多次、奖品又加积分/券接口，再另加时间。

## 不要写进工期里的（甲方 1.4）

服务器、运行环境、域名证书、小程序登录、发券等第三方能力：他们提供接口和权限，你不负责环境本身，也不承担这些不到位导致的延误。

## 原型图为什么由你出

对方点名开发老师交原型。按「可点击流程」交，避免被理解成出设计稿（那是 Chiho 的单页 DEMO / 视觉素材）。
