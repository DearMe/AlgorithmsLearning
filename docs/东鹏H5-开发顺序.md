## 现在做：东鹏换用户（已确认）

进页打开 `https://wx-bak.xdp8.cn/get/openid/from/gzh?callbackUrl=我们H5`，回调带 `wxOpenid`。

我们侧：

1. 读 `wxOpenid`，POST 给我们后端换 token，并从地址栏去掉该参数
2. 按公众号 openid 建/更新 `act_user`
3. 答题、抽奖、填地址只带我们 token

无 `wxOpenid` 且无 token：跳回东鹏授权地址。第一期不调他们会员接口。开发可用固定测试 openid 跑通抽奖，联调再接真授权。

## 现在做：抽奖逻辑（按附件一，服务端裁决）

| 规则 | 实现 |
|------|------|
| 未授权 | 不能玩 |
| 已参与 | 直接结果页，不能再抽（次数 X 若 >1，按剩余次数） |
| 未答完 5 题 | 不能抽 |
| 答对 < 3 | 不能抽，回首页 |
| 答对 ≥ 3 | 可以抽一次（若 X>1，按配置） |
| 点「开始抽奖」 | 服务端先开奖再让前端播动画，结果以服务端为准 |
| 库存为 0 | 该奖不再中，落到未中奖或下一档 |
| 实物中奖 | 填姓名、电话、地址后才算领取 |

开奖过程：校验资格 → 按后台概率抽 → 扣库存（Redis 防超卖）→ 写抽奖记录。  
幂等：同一用户同一场重复点「开始抽奖」，返回已有结果，不连抽。

次数 X、奖品、概率后台可配，先给默认：X=1；谢谢参与 + 1～2 个实物占位。
