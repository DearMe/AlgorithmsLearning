# 抽奖与后台 — 我们系统接口草案

给现有 ThinkPHP 项目用。东鹏只出现在「换用户」一个适配类里。

## 表（建议）

- `act_user`：id, openid, unionid, member_id, mobile, 我们的登录信息
- `act_question`：题目、选项 JSON、正确答案、是否启用
- `act_attempt`：用户一场答题（5 题快照、当前第几题、答对题数、状态）
- `act_answer_log`：每题对错
- `act_prize`：名称、类型、概率、库存、剩余、图
- `act_draw`：用户、奖品、状态（待领/已领/未中）、时间
- `act_address`：抽奖记录 ID、姓名、电话、地址
- `act_config`：次数 X、满 N 题可抽、活动开关

## C 端（需登录，我们 token）

| 接口 | 作用 |
|------|------|
| `POST /api/auth/exchange` | ticket 换我们 token（内部调东鹏适配） |
| `GET /api/activity/me` | 是否已参与、剩余次数、上次结果 |
| `POST /api/quiz/start` | 开一场，随机抽 5 题（不回传正确答案） |
| `POST /api/quiz/answer` | 答一题，回对错和下一题或结算 |
| `POST /api/draw/start` | 校验 ≥3 且未抽过，开奖，回奖品 |
| `POST /api/draw/address` | 实物填地址 |

## 后台

| 接口 | 作用 |
|------|------|
| 题库 CRUD | 配 5 题来源 |
| 奖品 CRUD | 概率、库存 |
| 配置 | X、满 3 可抽、开关 |
| 名单列表/导出 | 答题 + 中奖 + 地址 |

## 东鹏适配（只改这里对接真接口）

```
DongpengUserClient::exchange(ticket) -> { openid, unionid?, memberId?, mobile? }
```

无文档时 mock 返回测试用户。有文档只改这一个类。
