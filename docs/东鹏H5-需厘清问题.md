# 需要跟东鹏厘清的问题（只围绕两点）

已定玩法：进入页面先微信授权 → 问答 → 问答结束后抽奖。

发给对方时不要给选择题，只问他们怎么换用户、怎么部署、权限能不能给到我方。

---

## 1. 如何换用户信息

进页就要微信授权，我们拿到人之后才问答、抽奖。请对方直接说明怎么把用户交给我们。

需要他们讲清：

- 进入 H5 后，我们用什么换用户（接口地址、参数、调用方是我们服务端还是前端）
- 换回来有哪些字段（openid、unionid、会员 ID、手机号、昵称等）
- 鉴权怎么做（签名、密钥、IP 白名单）
- 测试环境地址、测试账号
- 登录态有效期、失败怎么处理（过期、未授权）
- 小程序 web-view 打开我们页面时，URL 上会带什么

## 2. 如何部署代码，权限能不能给到我方

代码要部署到他们侧。请对方直接说明发布方式和权限。

需要他们讲清：

- 部署在哪（机器 / 容器 / 现有 PHP 环境），PHP、MySQL、Redis、Nginx 情况
- 公网 HTTPS 域名、证书、小程序业务域名谁配、校验文件谁放
- 我方有没有服务器 SSH / 堡垒机、发布流水线、域名解析、小程序后台（业务域名、体验版）权限
- 没有完整权限的话，能开哪些：体验者、测试环境发布、日志查看
- 发布流程：谁发、怎么发、出问题怎么回滚
- 抽奖后台怎么访问、账号谁开
- 接口人是谁
