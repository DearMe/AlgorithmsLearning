# 东鹏微信小程序 H5 问答 / 海报 / 抽奖活动 — 技术对接问题清单

> 用途：发给东鹏技术，用于一次对齐嵌入方式、用户身份、分享海报、抽奖履约、环境与上线节奏。  
> 我方现有能力：ThinkPHP + MySQL + Redis + Nginx + Vue3，已有微信 H5 活动项目可复用。  
> 活动形态：H5 问答 → 生成海报并保存 → 抽奖；抽奖需独立后台。H5 嵌入东鹏微信小程序。

请对方按模块回复。标了 **【阻塞】** 的项不确认就无法排期开发；标了 **【建议会前给到】** 的请尽量会前书面回复。

## 3. 海报生成与保存【阻塞】

微信小程序 web-view 内，H5 **不能**直接调 `wx.saveImageToPhotosAlbum`，也 **不能**稳定用微信 JS-SDK 的分享接口。保存相册、转发卡片通常要小程序配合。

34. 海报形态：问答成绩海报 / 邀请海报（带太阳码或小程序码） / 两者都要？
35. 海报上要带：品牌 KV、用户头像昵称、答题分数、奖品图、小程序码、活动规则短链、门店信息？请给设计规范或 PSD。
36. 小程序码 / 太阳码：  
    谁来生成？用东鹏 AppID 还是我方？scene 参数规则、数量上限、是否要带渠道？
37. 「保存海报」的验收标准：  
    - A. 必须写入系统相册（需小程序：downloadFile + saveImageToPhotosAlbum + 用户授权）  
    - B. 预览大图，用户长按保存（iOS 较稳，Android 视内核）  
    - C. 仅用于转发小程序卡片，不强制落相册
38. 若选 A：小程序是否已有 `scope.writePhotosAlbum` 授权文案？隐私协议里是否声明「保存相册」？未声明会导致提审拒。
39. 海报图传到小程序侧的方式：  
    H5 canvas 出图 → 上传我方 OSS 得 HTTPS URL → `postMessage` 给小程序下载保存  
    是否允许图片域名配到 downloadFile 合法域名？单张大小限制？
40. 是否禁止用户截屏外传？做不做水印、防伪码？

## 附录 A：我方技术约束（方便东鹏评估）

- 前端：Vue3 H5，适配微信内置浏览器；在小程序 web-view 内通过 `wx.miniProgram` 与宿主通信。  
- 后端：ThinkPHP，MySQL 存活动/题库/抽奖/中奖，Redis 做库存与限流。  
- 网关：Nginx，HTTPS。  
- **做不到、必须东鹏小程序配合的：** 保存到系统相册、分享卡片 title/image/path、手机号一键授权、小程序码生成（用东鹏 AppID 时）、订阅消息、小程序支付。
